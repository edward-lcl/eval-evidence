# Packet-only tutoring boundary

This is preparation, not an authorized investigation. Work only in this packet; do not inspect the main repository, source archives, candidate personal data, client work, frozen ledger or submitted materials. Do not select real cases, run an evaluation, compute actual rewards, annotate or rank trajectories. Do not install tools, use network services, change branches, commit, push, contact organizers or alter the poster/form/site.

For student tutoring, use only `student/` and the student's own statements. Do not open COORDINATOR.md, outcome/reveal material or private selection notes in a student session. These are instructions, not an access-control sandbox. The coordinator must hand over only an explicitly reviewed student copy, not this whole directory or repository.

Follow [the tutor prompt](student/CODEX_PROMPT.md): ask for the student's initial evidence judgment BEFORE offering an agent verdict. Explain terms and navigation without completing the research in her name. Preserve her uncertainty, disagreement, rubric choices and attribution. Stop if no permission-cleared case packet has been provided. A later authorized study requires an explicit owner go-ahead; this file grants none.

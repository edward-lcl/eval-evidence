# Proposed small study—not a frozen protocol

## Question and ownership
The student chooses or justifies one intelligible behavior criterion before case selection is frozen. The confirmation question in the reading guide is an option, not an answer or required rubric. Record her rule, ambiguity handling and agreement in RUBRIC.md. No novelty or discrepancy is required. This is a small descriptive reading exercise, not a representative estimate or model ranking.

## Proposed set
Six records: three task IDs, each represented once in each of two historical source files. Choose one fixed trial value per file and use that same value for all three task IDs in that file. Trial values and IDs are **not selected yet**.

Before inspecting outcomes, the student and coordinator agree a task-level selection criterion and deterministic tie-break/order. The criterion must be reward-independent: no picking failures, suspicious rewards, apparent policy violations or interesting model differences. The coordinator records any prior exposure and the metadata used to select. If truly outcome-independent selection cannot be established, disclose that limitation rather than claiming blindness.

The coordinator later freezes an explicit list of file identity + task ID + trial for all six records. Validate uniqueness and presence before handing it over. No automatic sampling and no replacements. Missing, unreadable, ambiguous and out-of-scope selected cases remain visible dispositions; stop or report incomplete coverage rather than silently substituting.

## Sequence
1. Informed interest, permission and organizer/owner gates first. Agree the criterion and rubric; then freeze cases and reading order.
2. Phase A: read only approved task instructions and trajectories, including the embedded historical policy. Do not provide top-level rewards, reward_info, reference actions/outputs or investigator conclusions.
3. Use the first frozen case for orientation **within the six**, not an additional pilot. Save the student's first judgment before any AI verdict. Record actual exposure and assistance chronology. If the rubric changes after this case, retain the original version and judgment; label the change as exploratory and never pretend the first case is newly unexposed.
4. Continue only if the student understands the task and wants to proceed. Save each initial judgment, evidence and uncertainty. Preserve partial completion if she stops.
5. After Phase A for the agreed set is saved, the coordinator separately releases outcomes and relevant reference material under the approved scope. Keep pre-reveal judgments unchanged; add reconciliation entries.
6. Write a short student-led interpretation with contradictory evidence and unresolved cases. A policy judgment and the stored reward may concern different targets. Matching labels do not prove validity; differing labels do not prove a benchmark error.

Use the full frozen set as the coverage denominator; distinguish selected, read, judged, ambiguous, out-of-scope and unexamined. Do not extrapolate to all airline tasks or compare overall model quality. Actual organizer requirements are unknown; follow the owner's statement pending confirmation. The original sole-authored submission remains unchanged.
